# A Dark Room — OpenArcade silent English edition

Original minimalist survival adventure by Michael Townsend and the Doublespeak Games contributors. Pinned source: https://github.com/doublespeakgames/adarkroom/tree/1fada4620b6c66bd07bf15a3f1eb8223df8bc1d7. The game is MPL-2.0; see LICENSE.md. Covered source files remain available here in source form under that license. The full English narrative, room, village, wilderness, combat, ship, fabricator and ending modules are retained. Audio files, logos, translations, marketing events and store/analytics services are not included. This is an independent silent edition, not the official commercial mobile app.

Dependencies: jQuery 3.7.1 (MIT), source https://github.com/jquery/jquery/tree/3.7.1, distribution https://github.com/jquery/jquery-dist/tree/3.7.1. jQuery Color 2.1.2 (MIT), source https://github.com/jquery/jquery-color/tree/2.1.2. Full dependency notices are in lib/. The original bundled base64, translation and swipe plugins are replaced with native browser adapters; there are no CDN requests.

Modifications: local save namespace, safe object-path state access instead of eval, JSON save import validation, native UTF-8 base64, silent audio adapter, mobile scrollable layout and directional buttons, controller directional input, local offline worker, no analytics or marketing event. The upstream fixed 700px game board is retained and scrolls on narrow screens; this is not a fully reflowed mobile layout. Controller covers movement and activation of focused controls; full controller menu navigation is not implemented. First online game visit must finish caching before offline use.
